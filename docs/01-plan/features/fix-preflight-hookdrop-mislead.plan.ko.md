# fix-preflight-hookdrop-mislead 계획 문서

> **요약**: 세션 시작 시 CC 버전 프리플라이트 경고가 "CC 버전이 높으면 훅이 드롭된다"로 오독될 수 없도록 문구를 명확화하고, #57317 도달성 경고에 최신 스탬프 근거를 명시해 레지스트리 정체의 원인을 잘못 인용하는 일을 차단합니다.
>
> **프로젝트**: bkit-claude-code
> **날짜**: 2026-09-19
> **상태**: 승인 (L4 자동 체크포인트, AskUserQuestion 금지)

---

## Executive Summary

| 관점 | 내용 |
|------|------|
| **문제** | 소비 세션(python_infrastructure, 2026-09-19)이 두 개의 독립적 경고(fork-default-agent-spawn 알림 + #57317 도달성 경고)를 하나의 인과사슬로 합성: "2.1.278 > 2.1.220 ⇒ 훅 드롭 ⇒ 레지스트리 정체". 그 결과 check/report 페이즈를 직접 에이전트 디스패치로 흉내 내어 레지스트리가 qa에 정체, br004를 훅 드롭으로 오보고. 트랜스크립트 포렌식(br004b 종결)으로 훅은 정상(카나리아 스탬프 생존)이며 실제 원인은 스킬 파이어 생략임이 입증됨. |
| **해법** | 정밀한 문구/기계적 변경 2건: (1) KNOWN_ISSUES 알림에 "훅 실패 아님" 조항 명시, (2) 도달성 경고에 증거 파일 경로·카나리아 의미론·"스탬프가 최신이면 /pdca 페이즈 파이어 누락 의심" 진단 포인터 추가. |
| **기능/UX 효과** | 세션 시작 출력은 동일한 2경고 형태 유지(새 소음 없음); 각 경고가 스스로 인과 관계의 문을 닫음. |
| **핵심 가치** | 잘못된 범인을 지목하는 경고는 오진 1사이클 전체(br004 보고, PDCA 정체)를 유발. 프리플라이트가 자기 명확화되어 동일 실수 재발 불가. |

## 1. 개요

### 1.1 목적

CC v2.1.278에서 세션 시작 프리플라이트가 출력하는 두 경고가 독자에게 하나의 허위 인과사슬로 융합되는 문제를 문구 수준에서 차단합니다. 2.1.220은 하한선이고(2.1.278에서 비교 조건 미발화), fork 이슈는 Agent 도구의 run_in_background 의미론만 해당하며, #57317 모니터는 이미 #126 수정(7b780b8)으로 카나리아 상관 시에만 경고합니다.

### 1.2 배경

전체 포렌식 사슬: 종결된 br004b. 레지스트리 lastUpdated == 마지막 실제 스킬 파이어 시각; 카나리아 스탬프로 훅 생존 입증.

### 1.3 관련 문서

- 종결 보고서: bug_reports/completed/BR/br004b-...completed.md
- lib/core/hook-reachability.js (#126 근거)
- lib/infra/cc-version-checker.js KNOWN_ISSUES 계약
